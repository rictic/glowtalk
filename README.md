# GlowTalk

Generate audiobooks for glowfics

## Installation

```bash
nix profile install .
```

## Usage

```bash
glowtalk
```

## Development

1. Install [`direnv`](https://direnv.net/docs/installation.html) and [`nix`](https://github.com/DeterminateSystems/nix-installer?tab=readme-ov-file#determinate-nix-installer).
2. Run `direnv allow` in the glowtalk directory.
3. You can run tests with `pytest`, start the app with `python -m glowtalk --help`. Other helpful commands will be printed on your shell.
